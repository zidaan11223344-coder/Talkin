# TalkinChat Bot — Railway

هذه النسخة تحافظ على تسجيل الدخول، الاتصال، دخول الغرف، الدعوات، وأوامر الإشراف الموجودة في البوت الهدف، وتضيف طبقة أوامر للأغاني والألعاب والهدايا.

## التشغيل المحلي

انسخ `.env.example` إلى `.env` واملأ القيم المطلوبة، ثم شغّل:

```bash
pip install -r requirements.txt
python bot.py
```

## أوامر الميزات المنقولة

| القسم | الأوامر |
|---|---|
| الأغاني | `اغنية اسم الأغنية` أو `موسيقى اسم الأغنية` |
| الألعاب | `ألعاب`، `نرد`، `حجر`، `ورق`، `مقص`، `تخمين 7` |
| الهدايا | `هدايا` لعرض الكتالوج، `هدية@رقم@اسم المستخدم` للإرسال |
| المساعدة | `مساعدة الوسائط` |

يبحث أمر الأغاني عن النتيجة الأولى ويرسل رابط الصوت إلى Talkin بنوع رسالة `voice`، وترسل الهدية كرابط صورة إلى Talkin بنوع رسالة `image`. إذا رفض إصدار الخادم رسالة الوسائط، يظهر الرابط/النص كبديل. لا تُحفظ بيانات الدخول أو ملفات Cookies داخل الكود.

يمكن إضافة Cookies يوتيوب في Railway عبر `YOUTUBE_COOKIES` أو الحسابات الإضافية من `YOUTUBE_COOKIES_1` إلى `YOUTUBE_COOKIES_10`. يمكن أيضاً استخدام `base64:` أو تحديد ملف عبر `YOUTUBE_COOKIES_PATH`. يدعم البوت كذلك `YOUTUBE_PO_TOKEN` و`YOUTUBE_PLAYER_CLIENTS`، ولا يطبع محتوى Cookies في السجلات.

عند تنفيذ أمر الهدية، ينشئ البوت صورة PNG جديدة من القالب الموجود في `assets`، ويكتب اسم المرسل واسم المستقبل بالعربية مع ألوان وزخرفة متغيرة. يجب ضبط `PUBLIC_BASE_URL` على رابط Railway العام إذا لم يكن `RAILWAY_PUBLIC_DOMAIN` متاحاً، لأن Talkin يحتاج رابطاً عاماً للوصول إلى الصورة.

## النشر على Railway

1. ارفع هذا المجلد إلى مستودع GitHub أو ارفعه كملف مشروع إلى Railway.
2. أنشئ خدمة جديدة من المستودع.
3. أضف المتغيرات الموجودة في `.env.example` من تبويب **Variables**.
4. لا ترفع ملف `.env` الحقيقي إلى GitHub أو داخل ملف ZIP عام.
5. سيكتشف Railway ملف `Dockerfile` ويشغل `python bot.py` تلقائياً.

لا تحتاج النسخة إلى `GROUP_TO_JOIN` للتشغيل. بعد اتصال البوت، أرسل له في الخاص: `دخول اسم_الغرفة`، وسيدخل الغرفة ويبقى فيها. المتغيرات الأساسية الوحيدة هي `BOT_ID` و`BOT_PWD` و`PUBLIC_BASE_URL`؛ بقية الإعدادات لها قيم افتراضية.

## ملاحظات مهمة

- يجب أن تكون بيانات `BOT_ID` و`BOT_PWD` صحيحة، وأن تكون `GROUP_TO_JOIN` باسم الغرفة المطلوب دخولها.
- إذا رفض الخادم هوية الجهاز، استخدم قيم الجهاز نفسه في `DEVICE_ID` و`DEVICE_MANUFACTURER` و`DEVICE_PRODUCT_MODEL` و`SDK`.
- عند ظهور خطأ اتصال أو دخول غرفة، يسجله البوت في Logs مع مرحلة الخطأ، مثل المصادقة أو WebSocket أو دخول الغرفة.
- تم تعطيل إعادة دخول الغرفة تلقائياً افتراضياً لمنع حلقة الخروج والعودة. اترك `AUTO_REJOIN=0`، ولا تغيّره إلى `1` إلا إذا أردت إعادة الدخول التلقائي.
