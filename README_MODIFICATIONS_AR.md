# التعديلات الجديدة

- إصلاح إرسال التفاعلات/النشر إلى الخاص عبر `dm_relay`: تحقق من نتيجة الإدراج + 3 محاولات تلقائية، وعدم إعلان نجاح خاص وهمي عند فشل قاعدة البيانات.
- إصلاح إشعار مشغل الأغنية في الخاص بعد تشغيل الصوت فعلياً.
- إضافة لعبة `مليون`: يكتب المستخدم «مليون»، يظهر «جاري البحث عن مليون»، ثم يفوز عشوائياً بمليون نقطة أو يحصل على رسالة الحظ، مع فاصل دقيقتين لكل مستخدم.
- عند الفوز تُنشأ بطاقة مليون باسم الفائز وتُنشر الصورة في جميع الغرف.
- الحرب العالمية تستخدم حالة واحدة مشتركة بين جميع الغرف، وتُرسل صورة الحرب عند انتهاء المباراة فقط.
- صور الألعاب متعددة الخطوات لا تظهر عند البداية؛ صور النتائج تظهر فقط بعد اكتمال الجولة.
- تحسين بطاقات النتائج بإطار وتصميم موحد وكتابة تفاصيل النتيجة داخل الصورة.
- تحسين إطار صور الهدايا مع بقاء اسم المرسل والمستقبل داخل الصورة.
