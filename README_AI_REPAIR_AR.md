# نظام إصلاح البوت بالذكاء الاصطناعي

النظام الجديد يعمل من **الخاص مع البوت** ومتاح لصاحب البوت فقط. يستخدم OpenAI Responses API للتشخيص، وتوجد أوامر فحص آمنة لا تغيّر source code تلقائياً. توثيق Responses API الرسمي: https://platform.openai.com/overview

## متغيرات Railway

أضف:

- `OPENAI_API_KEY` = مفتاح OpenAI API
- `OPENAI_MODEL` = `gpt-5.6-luna` (اختياري)
- `OPENAI_IMAGE_MODEL` = `gpt-image-2` (اختياري)

## الأوامر في الخاص

- `اصلاح` — عرض مركز الصيانة
- `اصلاح فحص` — فحص Python وFFmpeg وPillow والجلسات والصور
- `اصلاح موسيقى` — فحص مكونات الموسيقى
- `اصلاح العاب` — فحص صور وألعاب البوت
- `اصلاح صور` — فحص نظام الصور والرابط العام
- `اصلاح سجل` — عرض آخر السجل
- `اصلاح ذكي مشكلة الموسيقى لا تعمل` — تحليل المشكلة بواسطة الذكاء الاصطناعي وإعطاء التشخيص والأمر المقترح
- `صمم صورة لبوت ألعاب بطابع فاخر` — إنشاء صورة وإرسالها في الخاص
- `اضف لعبة صيد الكنز | لعبة حظ وجمع نقاط` — إنشاء لعبة قابلة للإضافة إلى البوت مع صورة مولدة بالذكاء الاصطناعي

الألعاب المضافة تُحفظ في `custom_games.json` وتعمل من خلال نظام الألعاب الموجود، وتظل محمية بتوثيق VIP.

> ملاحظة: الذكاء الاصطناعي لا يملك صلاحية تنفيذ كود Python عشوائي أو استخراج الأسرار/الكوكيز. إصلاحات source code المعقدة تُعرض كتشخيص واقتراح بدلاً من تنفيذ غير آمن داخل الإنتاج.
