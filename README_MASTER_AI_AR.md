# نظام الماستر الذكي

## الأوامر الرئيسية
- `أوامر الماستر`
- `حالة البوت`
- `اصلاح ذاتيا`
- `اصلاح ذكي مشكلة ...`
- `اضف لعبة الاسم | الوصف`
- `تشغيل اختبار@command`
- `إيقاف اختبار@command`
- `اعتماد لعبة command`
- `حذف لعبة command`
- `اضف امر اسم | الرد`
- `حذف امر اسم`
- `تعطيل امر اسم`
- `تفعيل امر اسم`
- `الأوامر المضافة`

الأوامر المضافة تُحفظ في `custom_commands.json` وتعمل داخل الغرف فوراً. يمكن استخدام `{user}` و`{username}` و`{room}` داخل الرد.

الإصلاح الذاتي آمن ومحدود: يصلح ملفات JSON التالفة، ينشئ المجلدات الناقصة، ينظف اختبارات غير موجودة، ويفحص صياغة Python. لا ينفذ كوداً مولداً من الذكاء الاصطناعي ولا يطلب أسرار البيئة.
