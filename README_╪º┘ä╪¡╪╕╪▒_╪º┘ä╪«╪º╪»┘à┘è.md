# الحظر الخادمي فقط

لا يضيف البوت الآن أي مستخدم إلى `bans.json`، ولا يقرأ الملف لإيقاف الرسائل محليًا. عند تنفيذ أمر الحظر أو عند اكتشاف كلمة محظورة، يرسل البوت طلب `ban_room_member` إلى Giant فقط. لذلك تبقى حالة الحظر ومصدر الصلاحية داخل Giant، وليس في ملفات البوت.

يبقى `bans.json` فارغًا فقط للتوافق مع الحزم القديمة؛ يمكن حذفه يدويًا بأمان لأن `bot.py` لم يعد يستخدمه.
