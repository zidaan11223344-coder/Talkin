# نظام توثيق VIP — جينات شات

تمت إضافة توثيق خاص للأغاني والألعاب والنشر.

## توثيق مستخدم
صاحب البوت فقط يكتب داخل الغرفة:

`vip@اسم_المستخدم`

بعد نجاح التوثيق يستطيع المستخدم:
- تشغيل الأغاني من YouTube / Spotify / TikTok.
- مشاركة الأغنية الحالية.
- استخدام جميع أوامر الألعاب المحمية.
- استخدام نظام النشر إذا كان لديه صلاحية الماستر أيضًا.

## إزالة التوثيق
صاحب البوت فقط:

`unvip@اسم_المستخدم`

## عرض الموثقين
صاحب البوت فقط:

`vips`

## المالك
يُقرأ المالك من `OWNER_USERNAME` أو `owner_username` في `config.json`، والمالك يعتبر موثق VIP تلقائيًا.

## ملاحظات
- الماستر وحده لا يمنح VIP تلقائيًا.
- نظام الألعاب يبقى بفاصل 30 ثانية لكل لعبة ولكل مستخدم.
- الأغاني تبقى بفاصل دقيقتين لكل مستخدم.
- تفاصيل الألعاب تبقى رسالة نصية بعد الصورة، بدون إعجاب/تعليق/كود أغنية.
