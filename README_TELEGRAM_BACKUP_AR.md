# النسخ الاحتياطي Telegram

يكفي الآن متغير واحد في Railway:

`TELEGRAM_BOT_TOKEN`

لا تحتاج إلى `TELEGRAM_BACKUP_CHAT_ID`.

## التشغيل

1. ضع `TELEGRAM_BOT_TOKEN` في Railway Variables.
2. افتح بوت Telegram وأرسل له `/start` مرة واحدة من الحساب الذي تريد استقبال النسخة فيه.
3. من خاص البوت أرسل `نسخ احتياطي`.

سيبحث البوت تلقائياً عن آخر محادثة خاصة تفاعلت مع Bot Telegram ويرسل إليها ملف النسخة الاحتياطية.

ملاحظة: Telegram لا يسمح للبوت بمعرفة Chat ID لشخص لم يتفاعل معه مسبقاً؛ لذلك إرسال `/start` مرة واحدة ضروري عند استخدام التوكن فقط.
